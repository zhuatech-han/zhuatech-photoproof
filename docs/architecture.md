# PhotoProof 业务与架构约定

知华科技（上海如静知华信息科技有限公司） · https://www.zhuatech.cn/ · 微信 zhuatech / zhuatech2。

## 使用范围

摄影师和摄影工作室管理客户项目、样片、客户选片和修图交付。照片只在自主部署实例存储；不调用AI修图、支付网关、邮件或云相册。经营主体可以有多个工作室部门，不提供跨公司SaaS隔离。原图仅在角色与项目范围验证后下载；客户交付前只读服务器生成的水印预览。

## 业务约定

1. 草稿项目保存客户、摄影师、修图人员、拍摄类型、拍摄日期、至少/至多选片张数、套餐含片数量、套餐金额和每张加选价。只允许JPEG/PNG；样片发布后锁定，文件不可覆盖。
2. 样片发布进入选片。客户选择照片并填写修图备注，提交前显示并确认费用；不足最低数量或超限不能提交。后台不能以员工身份伪造客户确认。
3. 提交后选片和金额冻结。修图人员上传与选中样片绑定的独立版本，全部选中照片有版本才能送客户审阅。客户请求修改退回修图；认可全部最新版本才达到待交付状态。
4. 已核实的外部收款和退款独立登记，不实际转账。金额不得溢出或截断。足额收款且客户认可最新版本后，摄影师才能开放原文件和ZIP下载；客户最终确认后归档。已经下载的文件不能远程收回。
5. 交付前可以有原因地重新开放选片；已有选片和修图版本保留在历史轮次中，旧轮次不能冒充当前交付。金额变化前检查已收款，必要时先登记实际退款。
6. 草稿修改、业务操作和选择均检查版本与权限；不自动重复未知结果的写入。取消和过期使客户图像访问失效，不删除审计与资金历史。
7. 管理端提供账号、角色、权限名称、菜单、部门、拍摄分类、系统参数与审计。客户账号固定客户绑定；临时分享只限一个项目，失效或撤销即时生效。

## 技术

Java21/Spring Boot/Security/JPA/Flyway/MySQL8.4；Vue3/Vite/Node24.19；Compose与非root Nginx。业务与审计在同一事务；照片使用随机文件键和独立持久卷，先验证真实文件格式与尺寸，再生成预览。磁盘和数据库须一致备份及恢复。发布前执行完整构建、全新MySQL、权限、状态与金额、实际上传下载、重启和独立恢复验证。
